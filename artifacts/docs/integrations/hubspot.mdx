Connect your HubSpot CRM to CommissionKit. The connector syncs **owners as sales reps** and **closed-won deals** for commission calculation.

## How data flows

```
HubSpot CRM                    CommissionKit
──────────                     ──────────────

Contacts / Company              (not synced)

Deal created               →    Deal created (stage mapped from HubSpot pipeline)
        │
        ▼
Deal stage changes         →    Stage updates on next sync
        │
        ▼
Deal marked closed-won     →    Payment status = "paid"
Deal in other stages       →    Payment status = "unpaid"
```

HubSpot is a CRM, not an ERP — it doesn't track payments. CommissionKit assigns `paymentStatus: "paid"` to closed-won deals and `"unpaid"` to deals in other stages. You can override this with manual payment tracking in CommissionKit.

## Stage mapping

HubSpot deal stages are normalized to CommissionKit's canonical stages:

| HubSpot stage | CKit stage |
|---|---|
| `appointmentscheduled` | `pending` |
| `qualifiedtobuy` | `pending` |
| `presentationscheduled` | `pending` |
| `decisionmakerboughtin` | `pending` |
| `contractsent` | `pending` |
| `closedwon` | `closed_won` |
| `closedlost` | `closed_lost` |
| Custom pipeline stages | `closed_won` (default fallback) |

The connector automatically discovers your pipeline stages via HubSpot's API. Any stage with `metadata.isClosed = true` is treated as closed-won and synced (if `syncClosedOnly` is enabled).

## Authentication

CommissionKit supports two HubSpot auth methods. Both are configured in your HubSpot account under **Settings > Integrations > Development** (you can also find **Development** in the left sidebar menu).

### Method 1: Service Key (simplest)

A Service Key is a single token — no OAuth redirect, no app registration. Best for testing or single-user accounts.

1. In HubSpot, navigate to **Development** → **Service Keys**
2. Click **Create service key**
3. Name it (e.g. "CommissionKit")
4. Select these scopes:
   - `crm.objects.owners.read`
   - `crm.objects.deals.read`
5. Click **Create**
6. Copy the generated token
7. In CommissionKit, go to **Integrations** → select **HubSpot CRM**
8. Choose **Private App Token** as the auth mode
9. Paste the token into **Access Token**
10. Click **Connect**

### Method 2: Legacy App (OAuth 2.0)

A Legacy App uses OAuth 2.0 — users are redirected to HubSpot to authorize CommissionKit, then redirected back. Supports webhook subscriptions for real-time deal updates.

<Warning>
HubSpot is sunsetting legacy public app creation. New HubSpot accounts created after May 26 2026 cannot create new legacy public apps. Existing accounts can create them until June 23 2026. Existing legacy apps continue to work. Learn more on the [HubSpot Developer Changelog](https://developers.hubspot.com/changelog/legacy-public-app-creation-sunset).
</Warning>

1. In HubSpot, navigate to **Development** → **Legacy Apps**
2. Click **Create app** → select **Public app**
3. On the **Basic Info** tab, enter:
   - **App name**: CommissionKit
   - **Description**: (optional)
   - **Logo**: (optional)
4. Switch to the **Auth** tab:
   - Enter a **Redirect URL**: `https://your-domain.com/api/integrations/hubspot/callback`
   - In the **Scopes** section, click **Add new scope** and add:
     - `crm.objects.owners.read`
     - `crm.objects.deals.read`
   - Set both as **Required** scopes
5. Click **Create app** at the bottom left
6. After creation, the Auth tab now shows your **Client ID** and **Client secret**. Copy them.
7. In CommissionKit, go to **Integrations** → select **HubSpot CRM**
8. Choose **OAuth 2.0 (Sign in with HubSpot)** as the auth mode
9. Enter your **Client ID** and **Client Secret**
10. Click **Connect with HubSpot** — you'll be redirected to HubSpot to authorize the app
11. After granting access, you'll be redirected back to CommissionKit. Sync begins automatically.

<Note>
Credentials (Client ID, Client secret) are only visible **after** you click **Create app** — they're hidden while the app is in draft mode.
</Note>

The Redirect URL and scopes are both configured on the **Auth** tab. Webhooks can be set up separately for your connected app to receive real-time deal change notifications.

### Localhost development

For testing locally:
- Redirect URL: `http://localhost:3000/api/integrations/hubspot/callback`
- HubSpot allows `http` for `localhost` redirects
- Set `APP_URL=http://localhost:3000` in your API `.env` file

## What syncs

| Entity | HubSpot source | CKit equivalent |
|---|---|---|
| **Reps** | `crm/v3/owners` — all non-archived owners | Rep (name = firstName + lastName, role = "Sales Rep") |
| **Deals** | `crm/v3/objects/deals/search` — by stage filter | Deal (amount, close date, owner, pipeline stage) |

## Prerequisites

- HubSpot account with access to **Deals** and **Owners**
- API access enabled (all HubSpot accounts have this by default)
- Either a Service Key or a Legacy App with the required scopes

## Sync schedule

After connecting, choose a sync interval from the **⋮** menu:

| Option | Interval |
|---|---|
| Every 10 min | Real-time sync |
| Hourly | Recommended for active pipelines |
| Daily | For stable pipelines |
| Manual only | No automatic sync |
