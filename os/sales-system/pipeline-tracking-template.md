## CRM Data Fields (Required for Every Lead)

**Company:**
- Company name
- Industry
- Size (employees)
- Website
- Location

**Contact:**
- Full name
- Title
- Email
- LinkedIn URL
- Phone (if available)

**Opportunity:**
- Source (LinkedIn, cold email, referral, inbound)
- Plan recommended
- Estimated close date
- Estimated value
- Probability (%)
- Next action
- Next action date

**Notes:**
- Discovery call notes
- Demo notes
- Objections raised
- Competitors mentioned
- Decision timeline
