# CommissionKit OS

The CommissionKit Operating System (OS) contains all business, go-to-market, sales, content, and operational playbooks for building and running CommissionKit.

## What lives here

| Folder | Purpose |
|--------|---------|
| `gtm/` | Go-to-market strategy: ICP, positioning, pricing |
| `content-system/` | Content engine: analysis, SEO pipeline, calendar |
| `sales-system/` | Sales tools: playbook, calculator, pipeline tracking |
| `crm/` | CRM research, agent workflows, and sales playbooks |
| `sops/` | Standard operating procedures for repeatable tasks |
| `contracts/` | Legal templates and agreements |
| `dashboard/` | Operational dashboards and decision tools |
| `skills/` | Business/agent skills for sales and marketing work |

## Quick start

1. Read `gtm/ideal-client-profile.md` to understand who we sell to.
2. Read `sales-system/sales-rep-playbook.md` for outreach and discovery.
3. Read `sops/` for step-by-step execution guides.
4. Read `crm/AGENTS.md` for the automated LinkedIn → Twenty CRM workflow.

## For agents

When working on business, sales, marketing, or operational tasks, read the relevant section above before acting. Always prefer the patterns documented here over inventing new ones.
