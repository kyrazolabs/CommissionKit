# Data Report Skill

Structured analytics and reporting.

## When to Use

- Monday Dashboard
- Monthly metrics review
- Funnel analysis
- Content ROI reports
- Agent performance reviews

## Method

1. Define the decision the report supports
2. Choose 3-5 key metrics (not 20)
3. Show trend, not just point-in-time
4. Highlight anomalies with context
5. Recommend action, don't just describe
