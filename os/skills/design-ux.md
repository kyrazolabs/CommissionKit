# Design UX Skill

UX design workflow and accessibility.

## When to Use

- New feature wireframes
- User flow optimization
- Design system updates
- Accessibility audits
- Mobile responsive reviews

## Method

1. Understand user goal (not just feature request)
2. Sketch 3 options: obvious, clever, radical
3. Choose based on usability + dev effort
4. Follow WCAG 2.1 AA minimum
5. Test with real users when possible
