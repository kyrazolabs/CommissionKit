# Feature Planning Workflow

**Owner:** @compass  
**Team:** Product

## Steps

1. **User feedback** — Review support tickets, surveys, interviews (from @pulse)
2. **Market research** — Analyze competitors, market trends (from @scout)
3. **Product brief** — Write problem statement, solution, success metrics
4. **Prioritization** — Score: Impact × Urgency × Feasibility
5. **Technical planning** — Route to @plan for architecture
6. **Roadmap update** — Add to Now / Next / Later in AFFiNE

## Product Brief Template

```
# Product Brief: [Feature Name]

## Problem
[What user pain does this solve? Cite real feedback.]

## Solution
[What are we building? How does it work?]

## Success Metrics
- [Metric 1] — Target
- [Metric 2] — Target

## Timeline
- [Phase 1] — [Date]
- [Phase 2] — [Date]

## Dependencies
- [Team/system needed]
```
