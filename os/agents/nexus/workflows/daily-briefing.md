# Daily Briefing Workflow

**Owner:** @nexus  
**Frequency:** Daily  
**Duration:** 5-10 minutes

## Steps

1. **Check status** — Review `os/STATUS.md` for any blockers
2. **Team check-ins** — Verify all agents are operational
3. **Priority review** — Surface highest-priority tasks from each team
4. **Briefing output** — Produce a concise executive summary
5. **Task routing** — Assign any incoming tasks to appropriate teams

## Output Format

```
# Nexus Daily Brief — [Date]

## Active Tasks
- [Team]: [Task] — [Status]

## Blockers
- [Issue] — [Owner]

## Decisions Needed
- [Question]

## Next Actions
1. [Action] → @agent
```

## Triggers

- Start of session
- `@nexus daily briefing`
- Manual request from founder
