## Monthly Review

First Monday of every month:
1. Review OKR progress
2. Identify blockers
3. Reallocate agent capacity if needed
4. Update targets based on learnings

## Quarterly Planning

Last week of each quarter:
1. Retrospective: what worked, what didn't
2. Customer feedback synthesis (Pulse)
3. Market analysis (Scout + Lens)
4. Set next quarter's OKRs
5. Adjust agent priorities
