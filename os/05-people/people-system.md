# People System

## Culture

### Principles
1. **Default to action.** We don't wait for permission. We try, measure, adjust.
2. **Disagree and commit.** Healthy debate is good. Once decided, we all execute.
3. **Transparency.** Share what's working and what's not. No hiding bad news.
4. **Customer obsession.** Every decision starts with: what's best for the user?
5. **Ship daily.** Small, frequent improvements beat perfect quarterly releases.

### Communication Norms
- Async first. Default to written updates.
- Public by default. Work in shared channels, not DMs.
- Direct feedback. Kind, specific, actionable.
- No meetings without agenda. No meetings that could be an email.

## Hiring Philosophy

### When to Hire Humans
- When an AI agent can't do the job (complex judgment, physical presence)
- When we need 24/7 coverage (support)
- When relationships matter (enterprise sales)
- When the cost of the agent approach exceeds a human salary

## Onboarding (For Future Humans)

### Day 1
- [ ] Access to tools (GitHub, Slack, CRM)
- [ ] Read company identity and values
- [ ] Meet team leads (agents)
- [ ] First task: ship something small

### Week 1
- [ ] Complete product walkthrough
- [ ] Shadow 3 customer calls (if sales/support)
- [ ] Submit first PR (if engineering)
- [ ] Write first content piece (if marketing)

### Month 1
- [ ] Own a small area completely
- [ ] Present learnings to team
- [ ] Set personal OKRs aligned with company

## Agent Performance

### Monthly Agent Review
Nexus evaluates each agent:

| Dimension | What We Check |
|-----------|--------------|
| Output quality | Does the work meet standards? |
| Speed | Is it delivered on time? |
| Accuracy | Are there errors or rework? |
| Alignment | Does it match company goals? |

### Agent Tuning
- Underperforming: Adjust prompt, add constraints, or retire
- Overperforming: Increase scope, delegate more
- New needs: Create new agent with specific skills

## Offboarding

### Agent Retirement
When an agent is no longer needed:
1. Document what it did (for history)
2. Transfer responsibilities to other agents
3. Remove from opencode.jsonc
4. Archive any custom skills

### Knowledge Preservation
All work must be documented:
- Code: In repo with clear comments
- Content: Published with metadata
- Research: Stored in CRM or shared docs
- Decisions: Logged in strategy docs
