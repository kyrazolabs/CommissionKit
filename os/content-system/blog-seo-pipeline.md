# Blog → SEO → Social Promotion Pipeline

## Overview
Every blog article follows a standardized pipeline from idea to published post to social promotion. This ensures SEO discipline, content quality, and maximum distribution.

---

## Phase 1: SEO Brief (Before Writing)

### Content Brief Template

```markdown
# Content Brief: [Article Title]

**Target Keyword:** [primary keyword, e.g. "sales commission tracking software"]
**Secondary Keywords:** [3-5 related terms]
**Search Intent:** [Informational / Commercial / Comparison]
**Target Word Count:** 1,500–2,500
**Content Type:** [How-to / Listicle / Case Study / Comparison]
**Lead Magnet CTA:** [which calculator/template to embed]

## Outline
1. Hook — pain point / statistic (real only)
2. What the problem looks like
3. Why current solutions fail
4. How CommissionKit solves it
5. Step-by-step setup guide
6. Real-world example / customer story
7. CTA — lead magnet + trial signup

## Internal Links
- Link to: [relevant blog post]
- Link to: [product page / pricing]
- Link to: [lead magnet]

## On-Page SEO Checklist
- [ ] Target keyword in H1
- [ ] Target keyword in first 100 words
- [ ] Target keyword in 1 H2
- [ ] Meta description 150-160 chars
- [ ] Alt text on all images
- [ ] 3-5 internal links
- [ ] 1-2 external links to authoritative sources
- [ ] URL slug contains target keyword
```

### Keyword Research Sources
1. **Ahrefs/SEMrush** (if budget) — search volume, difficulty, competitor gaps
2. **Google "People Also Ask"** — free, real user questions
3. **Reddit r/sales + r/salesops** — actual pain points in user language
4. **Competitor blog comments** — what readers are asking for

---

## Phase 2: Writing & Publishing

### Writing Rules
- First person only ("I built", "we shipped")
- Zero fake statistics — only PLATFORM.md facts or real founder experience
- Short paragraphs (2-3 sentences max)
- Bullet lists for scanability
- Screenshot every 300 words minimum

### Publishing Checklist
- [ ] Run through Grammarly/Hemingway (readability grade 8-10)
- [ ] Compress all images (< 100KB each)
- [ ] Set canonical URL
- [ ] Add structured data (Article schema)
- [ ] Submit to Google Search Console
- [ ] Add to content calendar

### Insert into Supabase
After publishing, run:
```bash
python3 /root/.hermes/scripts/ck-blog-insert.py \
  --title "Article Title" \
  --url "https://commissionk.it/blog/slug" \
  --summary "One-paragraph summary for social promo" \
  --keywords "keyword1, keyword2"
```
This creates a `blog` row that the content cron reads for promotion.

## Phase 3: Social Promotion (Auto-Generated by Cron)

When the CK Daily Content cron sees a blog article in Supabase (platform: 'blog', last 7 days), it generates:

### X Posts (2 per article)
**Post 1 — Hook + Value**
```
I wrote about [topic].

The thing nobody tells you: [one surprising insight].

Full breakdown + free [lead magnet] → [URL]

#SalesOps #Commission
```

**Post 2 — Stat + CTA**
```
[Real stat from article].

Here's how we fixed it at CommissionKit:

[URL]

#SalesComp
```

### LinkedIn Post (1 per article)
Longer form: 2-3 paragraphs. Personal story angle. Ends with CTA to read + comment.

### Reddit Post (1 per article, r/salesops only)
Value-first summary. No direct link in post body — link in comment. Disclose affiliation.

### Newsletter Snippet (1 per article)
3-paragraph email: hook, key insight, CTA to read full article.

---

## Phase 4: Repurposing (Manual, Weekly)

Every Monday, the content manager (AI or human) takes the week's blog article and creates:

1. **X Thread** (5-7 tweets) — pull the best points into a thread
2. **Carousel** (5-8 slides) — key stats/tips as visual slides
3. **Short Video Script** — 60-second Loom/TikTok/Reels script
4. **Quote Graphics** — 3 pull quotes as branded images

---

## Phase 5: Performance Review (Weekly)

Every Monday at 9 AM KSA:

```bash
python3 /root/.hermes/scripts/ck-content-review.py
```

Outputs:
- Top 3 posts by engagement score
- Bottom 3 posts (what to stop doing)
- Blog traffic from Search Console (if API connected)
- Keyword ranking changes
- Recommendations for next week
