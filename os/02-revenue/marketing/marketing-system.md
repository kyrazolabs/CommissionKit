# Marketing System

## Content Strategy

### Blog Pipeline
**Target:** 2 posts per week
**Word count:** 1,500-2,500 words each
**SEO focus:** Sales commission management, spreadsheet alternatives, sales ops tools

### Content Pillars
1. **Commission Management** — How-to guides, best practices
2. **Sales Operations** — Tools, processes, efficiency
3. **Rep Experience** — Transparency, motivation, fairness
4. **Integrations** — CRM, ERP, workflow automation
5. **Product Updates** — Feature releases, case studies

### Lead Magnets
- Commission calculator (free tool)
- Commission plan template (spreadsheet → upgrade to CK)
- Sales comp guide (PDF)
- ROI calculator (for CFOs)

## Social Strategy

### Channels
- **X/Twitter:** 2 posts/day — hooks + insights
- **LinkedIn:** 1 post/day — personal stories, industry insights
- **Reddit:** 3-5 comments/week — r/salesops, r/sales (value-first)

### Rules
- Never drop links randomly
- Always disclose: "I built CommissionKit to solve this"
- Be helpful first, mention product second
- Track engagement weekly

## SEO Strategy

### Target Keywords
- Primary: "sales commission tracking software"
- Secondary: "commission calculation spreadsheet", "sales comp management", "automate commission calculations"
- Long-tail: "how to track commissions for sales team", "best commission software for SaaS"

### On-Page Checklist
- [ ] Target keyword in H1
- [ ] Target keyword in first 100 words
- [ ] Meta description 150-160 chars
- [ ] 3-5 internal links
- [ ] 1-2 external authority links
- [ ] Alt text on all images
- [ ] URL slug contains keyword

## Email Marketing

### Sequences
1. **Welcome** (Day 0) — Product overview + quick start
2. **Onboarding** (Day 1-7) — Feature highlights, tips
3. **Re-engagement** (Day 30) — What's new, case study
4. **Nurture** (Monthly) — Blog roundup, industry news

### Newsletter
- Frequency: Weekly
- Format: 3 paragraphs — hook, insight, CTA
- CTA: Read latest blog post or try calculator
