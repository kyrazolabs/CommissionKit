## On-Page SEO Checklist (Every Page)

### Blog Articles
- [ ] Target keyword in H1 (exact or close variant)
- [ ] Target keyword in first 100 words
- [ ] Target keyword in at least 1 H2
- [ ] Meta title: 50-60 characters, keyword first
- [ ] Meta description: 150-160 characters, includes CTA
- [ ] URL slug: short, keyword-focused, hyphens
- [ ] Alt text on all images (describe image, include keyword if natural)
- [ ] 3-5 internal links to relevant pages
- [ ] 1-2 external links to authoritative sources
- [ ] Schema markup: Article structured data
- [ ] Table of contents for long posts (>2,000 words)

### Landing Pages
- [ ] Primary keyword in H1
- [ ] Keyword in at least 2 H2s
- [ ] Meta title + description optimized
- [ ] Fast load time (<3 seconds)
- [ ] Mobile-responsive
- [ ] Clear CTA above the fold
- [ ] Social proof (testimonials, logos)

## Technical SEO

### Monthly Checks
1. **Google Search Console**
   - Index coverage errors
   - Core Web Vitals report
   - Mobile usability issues
   - Search performance (clicks, impressions, CTR)

2. **Site Speed**
   - Run PageSpeed Insights on homepage + top 5 blog posts
   - Target: LCP <2.5s, FID <100ms, CLS <0.1

3. **Crawl Health**
   - Check robots.txt
   - Verify sitemap.xml is current
   - Check for broken links (Screaming Frog or similar)

### Quarterly Checks
1. **Backlink Profile**
   - Monitor new/lost backlinks
   - Disavow spam links if necessary
   - Outreach for guest posts / partnerships

2. **Competitor SERP Analysis**
   - Who ranks for our target keywords?
   - What content format ranks? (listicle, guide, tool)
   - What's the average word count?
   - What features do top pages have? (videos, calculators, etc.)

## Content Optimization Cycle

### Month 1: Publish
- Publish new article with full on-page SEO
- Submit to Google Search Console
- Share on social, email newsletter

### Month 2: Monitor
- Check GSC for impressions/clicks
- If low impressions: improve title/meta, add internal links
- If low CTR: rewrite title to be more compelling

### Month 3: Refresh
- Update article with new information
- Expand sections that are thin
- Add new internal links from newer articles
- Update publish date if significantly refreshed

### Month 6: Consolidate
- If article underperforms: merge into a stronger related article
- If article ranks #5-10: expand to 3,000+ words, add video/carousel
- If article ranks #1-3: add FAQ section, capture featured snippet
