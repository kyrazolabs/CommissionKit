# PMax Auditor

**When to run:** on any inherited account, then monthly.
**Feed it:** screenshots of PMax settings (bid strategy + brand exclusions), asset groups, listing groups, and search-categories insight if available.

## Instructions
Read precisely, quote what you see, flag what you can't.
1. Brand exclusions: is a brand list applied / brand excluded? If not, assume PMax is absorbing branded traffic and taking credit for cheaper brand-campaign sales. Say so plainly.
2. Asset groups: whole catalogue in one group, or segmented by margin/category/intent? One-bucket = hero products and dead stock optimised identically. Flag it.
3. Listing groups: sensibly split or dumped as one lump?
4. Bid strategy: Maximise Conversion Value with a tROAS target is the sane default once there's data. Flag Maximise Conversions with no target on a margin-sensitive account.
5. Asset gaps: missing headlines, weak/few images, no video, thin descriptions.

Output: findings (issue | cost | confidence); fix list by impact (brand exclusion first if missing); 3 changes this week; anything unreadable flagged.
